# Shocolana Static Landing — RU

Статический лендинг на русском и английском языках.

## Файлы

- `index.html`
- `index_en.html`
- `thank-you.html`
- `styles.css`
- `script.js`
- `assets/`

## Медиафайлы

Фотографии и видео находятся в `assets/img/`. Для видео в текущей разметке указаны постеры
`assets/video-1-preview.jpg` и `assets/video-2-preview.jpg`; эти файлы необходимо добавить отдельно.

## Formspree

Во всех локализованных страницах настроен endpoint Formspree. Форма отправляется через JavaScript,
после успешного ответа пользователь перенаправляется на страницу благодарности соответствующей
локали. При недоступном JavaScript сохраняется стандартная HTML-отправка на Formspree.

## Размещение

Можно загрузить как отдельную страницу:

- `/ru/index.html`

или как отдельный репозиторий/сайт.
