# Shocolana Static Landing

Статический мультиязычный лендинг на английском, русском, словацком,
сербохорватском и словенском языках.

## Файлы

- `index.html` — основная английская версия
- `index_ru.html` — русская версия
- `index_sk.html` — словацкая версия
- `index_sh.html` — сербохорватская версия
- `index_sl.html` — словенская версия
- `index_en.html` — совместимый alias английской версии
- `thank-you*.html` — локализованные страницы благодарности
- `privacy-policy.html` — единая политика конфиденциальности на английском языке
- `styles.css`
- `script.js`
- `assets/`

## Медиафайлы

Фотографии и видео находятся в `assets/img/`. Страницы используют оптимизированные WebP-изображения
и H.264-видео без отдельных постеров.

## Formspree

Во всех локализованных страницах настроен endpoint Formspree. Форма отправляется через JavaScript,
после успешного ответа пользователь перенаправляется на страницу благодарности соответствующей
локали. При недоступном JavaScript сохраняется стандартная HTML-отправка на Formspree.

## Размещение

Корневой `index.html` является основной английской страницей сайта. Остальные локали доступны
через файлы `index_ru.html`, `index_sk.html`, `index_sh.html` и `index_sl.html`.
